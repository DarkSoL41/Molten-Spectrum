# MOLTEN SPECTRUM

**A metal-smelting Sokoban with lasers and spectra for the ZX Spectrum 48K / 128K.**
© 2026 DarkSoL41 · discord: `darksol41`

---

## About

The old **Red Crucible Works** is back in business, and you are its new smelter. Push ingots of copper, tin, zinc, iron, carbon and nickel around the shop floor, melt them in pots, make bronze, brass, steel and stainless steel, and fill the moulds of every order.

Later shops add acid baths, copper vitriol, one-way gates — and light: load a laser with metal and its beam carries the colours of that metal. Bend beams with mirrors, split them with prisms, feed spectrometers that open spectral doors, and heat cold pots with light.

No time limit, no lives, no randomness. Every move can be undone, every level was checked by a solver, and every level has a **par**. Solve it in par for a **MASTER** mark.

## Features

- **150 levels in 15 chapters** — from gentle lessons to very hard expert puzzles (80 levels in 8 chapters on a 48K machine)
- 6 metals and 6 real alloys: bronze, brass, steel, cupronickel, nickel silver, stainless steel
- pots, moulds, acid and vitriol baths, one-way gates, lasers, mirrors, prisms, spectrometers, spectral doors, cold pots
- smooth movement, undo up to 512 moves, restart, a graphical in-game manual
- original AY techno soundtrack (128K), beeper sound effects on every machine
- a four-letter code for every level
- keyboard (QAOP, cursor keys), Sinclair and Kempston joysticks

## How to play

Load `MoltenSpectrum.tap` in any ZX Spectrum emulator (Fuse, Spectaculator, Unreal Speccy, ZEsarUX, Retro Virtual Machine…) or on a real machine with `LOAD ""`. The game detects 48K / 128K by itself.

| Key | Action |
| --- | --- |
| Q A O P (or cursor keys / Sinclair / Kempston) | walk, push |
| U or Z (fire) | undo — hold to undo many moves |
| R, R | restart the level |
| H | manual |
| S | sound on / off |
| BREAK | pause: continue / manual / quit |

Fill every mould with an ingot of its material — and, where there are spectrometers, make them all see exactly their target colours. Push an ingot into a pot to melt it, push the second metal of a recipe in, and push the finished alloy out:

| Alloy | Recipe |
| --- | --- |
| BZ bronze | Cu + Sn |
| BS brass | Cu + Zn |
| ST steel | Fe + C |
| CN cupronickel | Cu + Ni |
| NS nickel silver | BS + Ni or CN + Zn |
| SS stainless steel | ST + Ni |

The full illustrated rules, all objects, the optics, the chapters and tips are in **[Manual.html](Manual.html)**.
